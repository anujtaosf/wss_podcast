ASSETS FOLDER
==============

This folder should contain your podcast audio files and any images.

AUDIO FILES:
- Add your podcast episode MP3 files here
- The website currently references "placeholder-audio.mp3"
- You can either:
  1. Name your files "placeholder-audio.mp3", OR
  2. Update the audioSrc paths in src/pages/Home.jsx to match your file names

IMAGES:
- Add any episode thumbnail images here
- Add host photos here
- Recommended image formats: JPG, PNG, WebP

EXAMPLE STRUCTURE:
assets/
  ├── placeholder-audio.mp3
  ├── episode-1-thumbnail.jpg
  ├── episode-2-thumbnail.jpg
  ├── host-anuhea.jpg
  ├── host-daniel-s.jpg
  └── host-daniel-b.jpg

NOTE: All files in this folder will be publicly accessible via the URL:
/assets/your-file-name.ext
